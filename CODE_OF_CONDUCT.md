# Code of conduct

Treat contributors and users with respect. Discuss ideas and code without harassment, personal attacks, discrimination, threats, unwanted sexual attention or publication of private information. Assume good intent while giving specific, actionable feedback.

Maintainers may edit or remove harmful content, close disruptive discussions or restrict participation. Enforcement should be proportionate and explain the reason when practical.

Report conduct concerns privately through the repository owner's GitHub contact options. If no private contact is available, do not post sensitive personal details publicly; ask for a private reporting channel in a short issue. Security disclosures follow SECURITY.md. No dedicated monitored email or response-time guarantee is advertised.
