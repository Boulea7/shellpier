# 常见问题

[文档首页](README.md)

### 需要管理员权限或 Windows 密码吗？

现代版以启动它的当前用户运行，不需要系统 sshd 或 Windows 密码。Legacy Bitvise 路线需要管理员安装与适用许可。

### 手机热点、校园网可以直接用吗？

先完成正常网络认证。双方能访问你的 HTTPS/WSS 中继时，可走出站连接；同一 Wi-Fi 也可能隔离客户端。没有预置公共中继，详见[使用场景](workflows.md)。

### Codex / Claude Code 怎么连接？

生成 `ssh-config` 后，将该配置交给支持 OpenSSH 的工具；也可调用内置 `check`、`connect`、`upload` 和 `download`。安装仓库中的 [skill](../skills/shellpier/SKILL.md) 后，确认 Agent 实际发现了它。

### 为什么不能像普通 ssh 一样打开交互终端？

当前提供 exec 与 SFTP，还没有 PTY。需要交互终端或图形桌面时，使用符合目标系统与网络条件的[其他工具](research.md)。

### 文件传输中断怎么办？

先检查目标文件和命令副作用，再重试。上传可能留下部分文件，需要核实后处理；下载失败会尝试清理本次新建的本地文件。传输不自动重放、不覆盖已有文件，也不随会话到期删除成功传输的文件。

### 到期后是否完全不留痕？

到期或停止会撤销会话。生成的凭据可按[命令手册](commands.md)清理；系统审计、网络日志以及远程命令已经修改的文件仍会保留。

### 可以一直运行吗？

`--ttl 0` 请求持续会话；中继还需开启 `--allow-persistent`。进程仍在前台，开机启动与服务管理需另行配置。

### 下载或运行被拦截怎么办？

按[安装指南](install.md)核对来源与校验和，使用认可的镜像或离线复制方式。通过系统或组织的正常审查流程处理拦截；当前发行没有 Windows 代码签名或 macOS 公证。
