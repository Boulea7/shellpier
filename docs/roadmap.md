# 路线图

[文档首页](README.md)

优先完善连接稳定性、平台覆盖与发行体验。以下方向暂无时间表。

| 状态 | 范围 |
|---|---|
| 已实现 | 直连与 WSS 中继、SSH exec、SFTP、TTL、邀请与撤销 |
| 已实现 | 交互 PTY、Agent 持久终端控制、有界 JSON 命令结果 |
| 已实现 | 命令 schema、目标能力发现、本机会话列表与 SFTP 文件操作 |
| 已实现 | 票据检查、分阶段诊断、目标别名、密钥生成、终端补全 |
| 已实现 | 目录传输与排除、单文件断点续传、SHA-256 校验与进度输出 |
| 已实现 | host 托管后台任务、operation ID 去重、有界日志与等待/取消 |
| 已实现 | 持久终端等待、输入 ID 查询与可选私有日志 |
| 已实现 | loopback 端口转发，目标端显式配置精确允许列表 |
| 已实现 | MCP stdio 接入，复用命令 schema、显式目标与有界执行 |
| 已实现 | 用户级服务计划、安装、启动、停止和卸载，显式登录自启 |
| 已实现 | 现代三平台 CI、离线发行包、中文和英文 README、Agent skill |
| 待测试 | Win7/8 新 Bitvise 独立实例的安装、到期与清理 |
| 待测试 | 最低系统版本、更多 CPU、真实校园代理与热点组合 |
| 待完善 | 发行包签名、公证与更完整的平台测试 |
| 待测试 | 用户级服务管理在不同桌面登录环境下的实际启停与恢复 |

后台任务和 operation ID 只保留在同一 host 进程内；单文件续传依赖原票据的主机身份、原文件及私有 journal。用户级服务不延长票据期限。各功能的使用方式与边界见[命令手册](commands.md)。

提出新功能时，请说明现有命令缺少的动作、目标平台与网络条件、可复现的使用场景。可复用当前链路的小功能优先，见[扩展指南](development.md)。
