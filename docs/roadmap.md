# 路线图

[文档首页](README.md)

以可复现的连接、明确的权限与可验证的撤销为优先。以下方向没有承诺时间表；欢迎通过 Issue 提供具体环境、问题和验收方法。

| 状态 | 范围 |
|---|---|
| 已实现 | 直连与 WSS 中继、SSH exec、SFTP、TTL、邀请与撤销 |
| 已实现 | 票据检查、身份核验、单文件上传下载、密钥生成、终端补全 |
| 已实现 | 现代三平台 CI、离线发行包、中文和英文 README、Agent skill |
| 待验收 | Win7/8 新 Bitvise 独立实例的安装、到期与清理 |
| 待验收 | 最低系统版本、更多 CPU、真实校园代理与热点组合 |
| 待完善 | 发布来源证明、操作系统签名与更完整的平台测试 |
| 待设计 | 有明确需求后再加入 PTY、传输恢复或长期服务管理 |

提出新功能时，请说明现有命令缺少的动作、目标平台与网络条件、最小验收场景。可复用当前链路的小功能优先，见[扩展指南](development.md)。
