[文档首页](README.md)

后台任务及其 operation ID 只保留在同一 host 进程内；终端输入 operation ID 保留在控制端同一 worker 生命周期内。单文件续传依赖原票据的主机身份、原文件及私有 journal。用户级服务不延长票据期限，也不自动重启崩溃进程或恢复任务。各功能的使用方式与边界见[命令手册](commands.md)。

OpenSSH 等工具的能力差异及本轮取舍见[工具对比](research.md)。UDP 漫游、多人协作终端、完整组织身份平台、操作审计与镜像删除尚未实现，也不属于当前版本承诺。

提出新功能时，请说明现有命令缺少的动作、目标平台与网络条件、可复现的使用场景。可复用当前链路的小功能优先，见[扩展指南](development.md)。
